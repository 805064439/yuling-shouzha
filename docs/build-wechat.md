# 发布到微信小游戏

Cocos Creator 对微信小游戏是一等目标平台，构建后产物需在 **微信开发者工具** 中预览 / 上传。

## 前置

1. 注册 **微信小游戏** 账号：https://mp.weixin.qq.com （个人/企业主体均可）。获取 **AppID**。
   - 测试期可用微信开发者工具的「测试号」，但正式发布必须有真实小游戏 AppID。
2. 安装 **微信开发者工具（稳定版）**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
3. 在 Cocos 里安装微信小游戏构建插件（Dashboard → 偏好设置 → 扩展商店 → 搜索「微信小游戏」安装，或构建面板里按提示安装）。

## 构建步骤

1. Cocos 顶部菜单 **项目 → 构建发布**。
2. 发布平台选 **微信小游戏**。
3. 填入你的 **AppID**（测试号可留空或选测试号）。
4. 构建资源服务器地址（可选）：若用微信云开发/CDN 托管远程资源可填，否则留空走本地包。
5. 点「构建」，完成后点「运行」会自动拉起微信开发者工具并打开产物目录。

## 主包 4MB 限制（关键）

微信小游戏**主包硬上限 4MB**，超出无法上传。本项目资源主要是 30 张立绘（约几百 KB～1MB 级别，具体以 build 后为准）：

- **首包控制**：把 `assets/resources/spirits/` 之外的逻辑代码放主包；立绘等资源建议走 **分包** 或 **远程资源**（构建时勾选「MD5 缓存」+「远程资源」，把 resources 托管到 CDN/云存储）。
- 当前 30 张立绘若总体积 < 4MB 可直接打主包；若超，则：
  - 在 `GameConfig.ts` 里把非首屏立绘（如真灵阶段）标记为远程加载；或
  - 用 **分包**（`build` 配置里把部分 scene/资源划到 subpackage）。
- 压缩 PNG（工具链已抠好的透明 PNG 多为已压缩；上架前可用 tinypng 再过一遍）。

## 上架合规（务必提前准备）

1. **软件著作权（软著）**：微信小游戏上架**必须**提交软著。周期约 **1–2 个月**，建议**立项第一天**就提交，与开发并行，别等做完再卡资质。
2. **版号 / 内购资质**：本项目含 **gacha 抽卡（内购 + 概率）**，属于微信重点审核对象：
   - 必须做 **概率公示**（在游戏内「召唤」页或官网公示各稀有度概率）；
   - 避免诱导消费、虚假宣传；
   - 涉及虚拟货币/内购支付的，通常还需要 **版号** 及相应资质，请提前核对《微信小游戏内购管理规范》。
3. **隐私协议**：需配置隐私保护指引并在首次启动时弹窗授权（微信强制要求）。

## 存档与账号（可选进阶）

- 本地存档当前走 `wx.getStorageSync`（见 `Save.ts`），单机可玩。
- 若要**跨设备/防作弊/社交**，建议接入 **微信云开发** 或自建后端：把 `Save.ts` 的 `backend()` 切换为云数据库读写即可，逻辑层其余代码无需改动。

## 真机预览

微信开发者工具里点「真机调试」或「预览」扫码，即可在手机上玩。注意手机与电脑同一网络，或走微信预览码。
